# Roadmap

## Phase 01: Architecture Foundation (Current)
- Node.js, Express, TypeScript Setup
- Security Middlewares
- Centralized Error Handling
- Docker Compose for DB and Redis

## Phase 02: Core Multi-Tenancy & Data Models
- Prisma Schema for Organizations, Users, Roles, Permissions
- Authentication and Authorization

## Phase 03: Travel Business Domain
- Tours, Schedules, Capacity, Pricing
- Bookings, Customers, Travelers

## Phase 04: Financial & Operations
- Payments, Invoices, Refunds
- Expenses, Vendors, Accounting
